# No Scroll

Safari extension that hides feeds on Facebook, Instagram, LinkedIn, Reddit and YouTube. Every rule can be toggled from the toolbar popup.

## Layout

- `extension/` — the web extension (edit here). `rules.js` decides which pages are blocked; `block.css` does the hiding.
- `NoScroll/` — Xcode app wrapper generated by `safari-web-extension-converter`. It references files in `extension/` directly; a new top-level file there must also be added to the Xcode project.

## Develop

```bash
node --test rules.test.js
xcodebuild -project NoScroll/NoScroll.xcodeproj -scheme NoScroll -derivedDataPath build -allowProvisioningUpdates
open build/Build/Products/Debug/NoScroll.app
```

Builds are signed with the project's Apple Development team (a free Personal Team works for your own Mac). To use another team, change Signing & Capabilities in Xcode. Unsigned builds (`CODE_SIGN_IDENTITY="-"`) need Safari → Settings → Developer → Allow unsigned extensions.

## Release

One-time setup (requires a paid Apple Developer account):

1. Xcode → Settings → Accounts: sign in, then Manage Certificates → + → Developer ID Application.
2. Create an app-specific password at account.apple.com, then store notarization credentials:
   ```bash
   xcrun notarytool store-credentials noscroll-notary --apple-id YOU@EXAMPLE.COM --team-id TEAM_ID
   ```

Each release: bump `version` in `extension/manifest.json`, commit, then:

```bash
TEAM_ID=YOUR_TEAM_ID scripts/release.sh
```

This archives, signs with Developer ID, notarizes, and uploads `NoScroll-<version>.zip` to GitHub Releases.
